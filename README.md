# Geek Fortune - Quiz Game

A pop culture quiz game built with React, Vite, and Supabase.

## 🌐 Live Site

**Public URL:** https://geek-fortune-project-1.vercel.app

The site is publicly accessible without authentication. If you see a password prompt, check the [VERCEL_PUBLIC_ACCESS.md](./VERCEL_PUBLIC_ACCESS.md) guide.

## 🚀 Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.

Run `npm run build` to build for production.

## 📦 Deployment

The project is deployed on Vercel. To deploy:

```bash
vercel --prod
```

## 🔧 Making the site public

If the site requires authentication, follow these steps:

1. Open https://vercel.com
2. Go to your project settings
3. Navigate to **Settings** → **Deployment Protection**
4. Disable **Password Protection**
5. Save changes

For detailed instructions, see [VERCEL_PUBLIC_ACCESS.md](./VERCEL_PUBLIC_ACCESS.md).

## 🎮 Features

- Quiz game with questions about videogames, music, and movies
- User registration and login
- Leaderboard
- User profiles with statistics
- Pixel art style UI

# Как сделать сайт публичным (без входа)

## ✅ Что уже сделано:

1. ✅ Проект задеплоен в Production на Vercel
2. ✅ Создан основной публичный URL: **https://geek-fortune-project-1.vercel.app**
3. ✅ Настроен правильный `vercel.json` для работы SPA

## 🔧 Что нужно сделать ВАМ:

### Шаг 1: Отключить Password Protection в Vercel

**Это нужно сделать в веб-интерфейсе Vercel:**

1. Откройте https://vercel.com в браузере
2. Войдите в свой аккаунт Vercel
3. Найдите проект **geek-fortune-project-1** в списке проектов
4. Нажмите на проект, чтобы открыть его
5. Перейдите в раздел **Settings** (Настройки) - это в верхнем меню
6. В левом меню выберите **Deployment Protection** (Защита деплоя)
7. Если там включена **Password Protection** (Защита паролем):
   - **Отключите её** (переключите в положение OFF)
   - Нажмите **Save** (Сохранить)
8. Готово! Теперь сайт будет доступен без пароля

### Шаг 2: Проверить доступ

1. Откройте URL в режиме инкогнито: **https://geek-fortune-project-1.vercel.app**
2. Или откройте на другом устройстве (телефоне) без входа в Vercel
3. Сайт должен открываться **без запроса пароля или авторизации**

## 🌐 Основной публичный URL:

**https://geek-fortune-project-1.vercel.app**

Этот URL должен работать на любом устройстве (компьютер, телефон, планшет) без требований авторизации.

## ⚠️ Важно:

- **НЕ используйте Preview URLs** (они требуют авторизацию)
- Используйте только **Production URL** (основной URL выше)
- Если после отключения Password Protection сайт всё ещё требует авторизацию:
  1. Подождите 1-2 минуты (настройки могут обновиться)
  2. Очистите кеш браузера
  3. Попробуйте в режиме инкогнито
  4. Проверьте на другом устройстве

## 📱 Доступ с телефона:

Основной URL **https://geek-fortune-project-1.vercel.app** должен работать на телефоне без требований авторизации, если Password Protection отключена.

## 🔍 Если проблема сохраняется:

1. Убедитесь, что вы отключили Password Protection в настройках Vercel
2. Проверьте, что вы используете Production URL (не Preview)
3. Попробуйте открыть сайт в режиме инкогнито
4. Проверьте на другом устройстве

Если проблема не решается, проверьте настройки команды/организации в Vercel - возможно, там есть дополнительные ограничения доступа.

# Как сделать сайт публичным на Vercel (без входа)

## ✅ Основной Production URL:

**https://geek-fortune-project-1.vercel.app**

Этот URL должен работать публично без авторизации.

## 🔧 Инструкция по настройке публичного доступа:

### Шаг 1: Отключить Password Protection

1. Откройте https://vercel.com в браузере
2. Войдите в свой аккаунт Vercel
3. Найдите проект `geek-fortune-project-1` в списке проектов
4. Нажмите на проект, чтобы открыть его
5. Перейдите в раздел **Settings** (Настройки)
6. В левом меню выберите **Deployment Protection** (Защита деплоя)
7. Если там включена **Password Protection** (Защита паролем):
   - Отключите её (переключите в положение OFF)
   - Нажмите **Save** (Сохранить)
8. Если есть другие настройки защиты - отключите их тоже

### Шаг 2: Проверить настройки проекта

1. В разделе **Settings** → **General** (Общие)
2. Убедитесь, что проект не находится в приватной команде/организации
3. Проверьте, что **Visibility** установлена в **Public** (если такая опция есть)

### Шаг 3: Проверить доступ

1. Откройте URL в режиме инкогнито: `https://geek-fortune-project-1.vercel.app`
2. Или откройте на другом устройстве без входа в Vercel
3. Сайт должен открываться без запроса пароля или авторизации

## 🌐 Альтернативные URLs:

## ⚠️ Важно:

- **НЕ используйте Preview URLs** - они требуют авторизацию Vercel аккаунта
- Используйте только **Production URLs** - они должны быть публичными
- Если сайт всё ещё требует авторизацию после отключения Password Protection:
  1. Подождите несколько минут (настройки могут обновиться)
  2. Очистите кеш браузера
  3. Попробуйте в режиме инкогнито
  4. Проверьте на другом устройстве

## 📱 Доступ с мобильных устройств:

Основной URL `https://geek-fortune-project-1.vercel.app` должен работать на любом устройстве (телефон, планшет, компьютер) без требований авторизации, если Password Protection отключена.

## 🔍 Проверка через CLI:

Вы можете проверить статус деплоя через команду:
```bash
vercel ls
```

Найдите деплоймент со статусом `● Ready` и `Environment: Production` - это публичный деплоймент.

## 📝 Примечание:

Если после всех настроек сайт всё ещё требует авторизацию, это может быть связано с настройками команды/организации в Vercel. В этом случае:
1. Проверьте настройки команды/организации
2. Убедитесь, что проект не находится в приватной организации
3. Свяжитесь с поддержкой Vercel, если проблема сохраняется

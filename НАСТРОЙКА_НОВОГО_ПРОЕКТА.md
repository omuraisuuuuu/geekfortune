# 🔧 Настройка нового проекта Supabase

## ✅ Что уже готово:

1. ✅ SQL скрипт для создания таблиц (`setup_new_supabase.sql`)
2. ✅ Инструкции по настройке (в этом файле)
3. ✅ Проект настроен для использования переменных окружения
4. ✅ Код готов к работе с новым проектом Supabase

## 📋 Что нужно сделать:

### Шаг 1: Получите ключи из нового проекта Supabase

1. Откройте: https://supabase.com/dashboard/project/qxkmwmrjsyjxmtydahct/settings/api
2. Скопируйте следующие ключи:
   - **Project URL** (например: `https://qxkmwmrjsyjxmtydahct.supabase.co`)
   - **anon public key** (длинный ключ, начинается с `eyJ...`)

**Сохраните эти ключи - они понадобятся в следующих шагах!**

### Шаг 2: Создайте таблицы в новом проекте

1. Откройте: https://supabase.com/dashboard/project/qxkmwmrjsyjxmtydahct/sql
2. Нажмите **New query**
3. Откройте файл `setup_new_supabase.sql` в проекте
4. Скопируйте весь код из файла
5. Вставьте в SQL Editor
6. Нажмите **Run** (или `Ctrl+Enter`)
7. Проверьте результат: должно быть сообщение "Success"

**Проверьте, что таблицы созданы:**
- Откройте: https://supabase.com/dashboard/project/qxkmwmrjsyjxmtydahct/editor
- Вы должны увидеть две таблицы: `users` и `leaderboard`

### Шаг 3: Настройте переменные окружения в Vercel

1. Откройте: https://vercel.com/aldiyars-projects-deeb61f1/geek-fortune-project-1/settings/environment-variables
2. Найдите или создайте следующие переменные:
   - `VITE_SUPABASE_URL` = `https://qxkmwmrjsyjxmtydahct.supabase.co`
   - `VITE_SUPABASE_ANON_KEY` = ваш anon public key (из шага 1)
3. Нажмите **Save**
4. Пересоберите проект:
   - Перейдите в **Deployments**
   - Найдите последний deployment
   - Нажмите **Redeploy** (или создайте новый deployment)

### Шаг 4: Проверьте работу

1. Откройте сайт: https://geek-fortune-project-1.vercel.app
2. Зарегистрируйтесь как новый пользователь
3. Сыграйте игру
4. Проверьте лидерборд
5. Проверьте в Supabase Table Editor, что данные сохраняются:
   - https://supabase.com/dashboard/project/qxkmwmrjsyjxmtydahct/editor
   - Должны появиться записи в таблице `users`
   - Должны появиться записи в таблице `leaderboard`

## 🎉 Готово!

После выполнения всех шагов проект будет работать с новым проектом Supabase!

## 🔍 Проверка

После настройки проверьте:

1. **Консоль браузера** (F12) - должны быть запросы к Supabase API
2. **Network tab** - должны быть запросы к `qxkmwmrjsyjxmtydahct.supabase.co`
3. **Supabase Table Editor** - должны появляться новые записи
4. **Vercel Environment Variables** - должны быть правильно настроены

## 🆘 Если что-то не работает:

1. **Проверьте переменные окружения** - они должны быть правильно настроены
2. **Проверьте таблицы** - они должны существовать в Supabase
3. **Проверьте RLS политики** - они должны быть созданы
4. **Проверьте консоль браузера** - должны быть запросы к Supabase
5. **Проверьте Vercel logs** - должны быть логи деплоя

## 📝 Примечания

- Переменные окружения в Vercel должны быть настроены для production
- После изменения переменных окружения нужно пересобрать проект
- Таблицы должны быть созданы перед использованием приложения
- RLS политики должны быть настроены для доступа к таблицам
